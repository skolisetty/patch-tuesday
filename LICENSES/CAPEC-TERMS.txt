MITRE CAPEC (Common Attack Pattern Enumeration and Classification) 2.1, STIX bundle
Source used by this project: https://github.com/mitre/cti, file capec/2.1/stix-capec.json
(downloaded by scripts/pull_data.sh to data/raw/mappings/stix-capec.json).

What this project keeps from it: CAPEC-to-ATT&CK technique ids (landing.cwe_attack_map), which
become technique_id / technique_name / tactic on cards whose mapping_source is cwe_capec.
